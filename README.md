### Hi, I'm Demir 👋

**Creative tools that start with the keyboard, not the mouse.**

I'm a software developer from Serbia. I studied English Language and Literature in Novi Sad and came to programming later than most. I'm blind and have used the JAWS screen reader for about twenty years, so every app I build — video, audio and photo editing, Windows tools, keyboards — I use myself, every day.

#### Why I code

My son turns two this November, and my wife writes children's songs. Making videos for her songs, I kept running into the same thing: so many genuinely useful apps are built for the mouse first, and keyboard and screen reader use comes last, if at all. It isn't hard to fix — it's just rarely the starting point.

So I start from there: apps that work fully from the keyboard and with a screen reader, and are just as comfortable for sighted users with a mouse. Same features for everyone, no separate "accessible mode".

#### What I'm working on

🎬 **Ultra Creative Suite** — open-source accessibility engine for creative software (video, audio, and photo editing)

🛡️ **Ultra Shield** — accessible digital security & self-defense app

⌨️ **Ultra Keyboard** — accessible custom keyboard

📷 **AI Camera** — AI-assisted scene description for blind and low-vision users, powered by Google Gemini

🧹 **Ultra Uninstaller** — removes programs even when their own uninstaller doesn't work with a screen reader, plus disk and startup tools

⬇️ **Ultra YouTube Downloader** — video and MP3 from YouTube, single videos or whole playlists

🌉 **Ultra Bridge** — which NVDA command matches which JAWS command, and back

Together, these make up a growing family of apps — every one built to work equally well for blind and sighted users, with accessibility as the starting point rather than an add-on.
