### Hi, I'm Demir 👋

**Creative tools that start with the keyboard, not the mouse.**

I'm a software developer from Serbia. I studied English Language and Literature in Novi Sad and came to programming later than most. I'm blind and have used the JAWS screen reader for about twenty years, so every app I build — video, audio and photo editing, audio description, Windows tools, keyboards — I use myself, every day.

#### Why I code

My son turns two this November, and my wife writes children's songs. Making videos for her songs, I kept running into the same thing: so many genuinely useful apps are built for the mouse first, and keyboard and screen reader use comes last, if at all. It isn't hard to fix — it's just rarely the starting point.

So I start from there: apps that work fully from the keyboard and with a screen reader, and are just as comfortable for sighted users with a mouse. Same features for everyone, no separate "accessible mode".

#### What I'm working on

**Creating**

🎬 **[Ultra Creative Suite](https://github.com/demirajvazi10-max/Ultra-Creative-suite)** — open-source creative software that works fully from the keyboard and with a screen reader: Ultra Video Editor, Ultra Audio Editor, Ultra Studio (photos), Ultra Composer (music), Ultra Record (multi-track recording), Ultra Captions (subtitles), Ultra Cast (screen recording) and Ultra Player (podcasts and audiobooks)

🎙️ **[Ultra Audio Description Maker](https://github.com/demirajvazi10-max/Ultra-AudioDescription-Maker)** — adds audio description to any video: AI writes what happens on screen, you check it, a natural voice speaks each description at the exact moment of its action, like on Netflix. A Windows program, a browser extension for Edge and Chrome, and an Android app

**Seeing and understanding**

📷 **[AI Camera](https://github.com/demirajvazi10-max/ai-camera-fan-edition)** — AI-assisted scene description for blind and low-vision users, powered by Google Gemini. [Try it on your phone](https://demirajvazi10-max.github.io/ai-camera-fan-edition/)

🌉 **[Ultra Bridge](https://github.com/demirajvazi10-max/Ultra-Bridge)** — which NVDA command matches which JAWS command, and back

**Everyday tools**

🧹 **[Ultra Uninstaller](https://github.com/demirajvazi10-max/Ultra-Uninstaller)** — removes programs even when their own uninstaller doesn't work with a screen reader, plus disk and startup tools

⬇️ **[Ultra YouTube Downloader](https://github.com/demirajvazi10-max/ultraYoutubeDownloader)** — video and MP3 from YouTube, single videos or whole playlists

🛡️ **[Ultra Shield](https://github.com/demirajvazi10-max/UltraShield)** — accessible digital security & self-defense app

⌨️ **[Ultra Keyboard](https://github.com/demirajvazi10-max/Ultra-Keyboard)** — accessible custom keyboard for Android

Together, these make up a growing family of apps — every one built to work equally well for blind and sighted users, with accessibility as the starting point rather than an add-on.
